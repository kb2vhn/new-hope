# Contributing to New Hope

New Hope is an early-stage personal research project. Contributions and agent-generated changes are not automatically accepted.

Start with [AGENTS.md](AGENTS.md), the [architecture baseline](docs/architecture/ARCHITECTURE.md), and the [roadmap](docs/roadmap/ROADMAP.md). Describe the exact affected component boundary, proposed behavior, risks, and tests. For architectural changes, create an ADR rather than silently changing the baseline. Do not assume a POSIX compatibility target, network stack, selected bootloader, or published license.

A draft change is not authorization to push or merge. Approval is scoped to the requested action. Test results must identify the environment and cannot equate a documentation-only check with an OS boot test.

**Licensing:** No license has been selected; contact the repository owner before assuming external reuse or redistribution permissions.
