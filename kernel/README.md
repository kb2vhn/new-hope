# Kernel ownership

Reserved for the future freestanding Rust microkernel. It will own scheduling, interrupt/exception receipt, physical/virtual memory mechanisms, isolation, IPC primitives, and mandatory UMI enforcement. No kernel crate or bootloader has been selected or implemented.

See [architecture baseline](../docs/architecture/ARCHITECTURE.md) and [ADR-0001](../docs/architecture/ADR-0001-MICROKERNEL-BOUNDARY.md).
